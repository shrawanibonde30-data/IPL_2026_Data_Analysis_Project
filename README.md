# IPL 2026 Data Analysis Project

## Overview
This project analyzes IPL 2026 season data to evaluate team performance, player 
statistics, and venue-wise trends across League stage matches.
The analysis was performed using SQL (MySQL) and Power BI.

## Tools Used
- SQL (MySQL)
- Power BI

## Key KPIs
- Total Matches Played
- Team-wise Wins
- Top Run Scorers & Wicket-Takers
- Venue-wise Runs and Wickets

## Dashboard Features
- Tournament Overview with season-level summary cards
- Match & Venue-wise Performance Analysis across multiple pages
- Player Performance Analysis (top scorers, top wicket-takers)
- Interactive bar charts, pie charts, and tables

## Key Insights
- RCB and PBKS were joint leaders in League stage wins, with 6 wins each out of 
39 matches played.
- Vaibhav Sooryavanshi was the leading run scorer of the season so far, with 
776 runs.
- Jofra Archer, Bhuvneshwar Kumar, and Kagiso Rabada were tied as the season's top 
wicket-takers, with 29 wickets each.
- M. Chinnaswamy Stadium, Bangalore recorded the highest total runs among all 
venues played so far.

## Project Structure
- excel_data (matches and ball-by-ball delivery datasets)
- sql_queries.sql (19 SQL queries covering team, player, and venue-wise analysis)
- Power BI Dashboards (Tournament Overview, Match & Venue Analysis, Player 
Performance Analysis)
